# TASKMAN visual human checklist

STATUS: AWAITING_HUMAN_REVIEW

- [ ] `taskman 1000` opens with an immediately legible table.
- [ ] PID and USER have a visible gap.
- [ ] CPU, LCPU, and AFF do not touch.
- [ ] STATE, CLASS, and Q do not touch.
- [ ] TIME+ and %CPU do not touch.
- [ ] KILL and MEM~ do not touch.
- [ ] The five group separators remain aligned.
- [ ] Header and rows use the same twelve semantic boundaries.
- [ ] No value invades a neighboring column.
- [ ] Long names truncate explicitly.
- [ ] WIDE remains organized and legible.
- [ ] COMPACT shows a real table and preserves `!100.0%`.
- [ ] Title, summary blocks, and footer do not overlap.
- [ ] Selection is immediately visible.
- [ ] RUNNING, ZOMBIE, and pending kill remain distinguishable.
- [ ] Refresh at 1000 ms has no perceptible blank flash.
- [ ] Pagination and navigation do not visibly clear the full region.
- [ ] ESC clears the region and returns to the shell.
